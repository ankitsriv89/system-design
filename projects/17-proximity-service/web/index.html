Key Concepts

  • Geohash — encode lat/lng to a hierarchical string; nearby cells share prefix
  • Redis GEO — GEOADD/GEORADIUS for O(N+log M) hot lookups, TTL via sorted-set score
  • PostGIS GIST index — durable spatial queries, history, analytics
  • Location TTL — stale entries evicted after 5 min; privacy by default
  • Visibility — PUBLIC / FRIENDS / HIDDEN; HIDDEN users never appear in results
  • Kafka fanout — downstream consumers react to location events asynchronously
