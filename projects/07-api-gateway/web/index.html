What is an API Gateway?

An API gateway is the single entry point for all client traffic into a microservices backend. Instead of exposing every service directly, the gateway handles cross-cutting concerns at the edge:

  • Routing — maps URL prefixes to upstream services
  • Authentication — validates API keys before requests reach services
  • Rate limiting — enforces per-key quotas using a sliding window in Redis
  • Observability — emits latency metrics, structured logs, and decision traces

The gateway separates into two planes: the data plane (proxy on :8088) handles millions of requests per second; the control plane (admin on :8089) manages config changes that reload the route table in <1 ms.
