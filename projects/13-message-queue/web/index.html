How It Works

Message Queue

A durable buffer between producers and consumers. Producers write messages to a topic; the queue persists them in append-only partitions. Consumers poll messages, which become invisible (in-flight) for a configurable visibility timeout. After processing, the consumer sends an ack. If the consumer crashes before acking, the message reappears after the timeout. Messages that exceed 5 delivery attempts are moved to the Dead-Letter Queue.
