Hybrid Fanout

On tweet.created, the fanout worker pushes the tweet ID into each follower's Redis sorted-set timeline (push / fanout-on-write). Authors above the celebrity threshold are skipped — their tweets are pulled from Postgres at read time (pull / fanout-on-read), so a celebrity tweet never triggers millions of writes.

Search & Trends

A second consumer indexes every tweet into OpenSearch. /v1/search is a full-text match; /v1/trends is a terms aggregation over hashtags in a 24h window. Both are eventually consistent — independent of the timeline path, so search lag never blocks the feed.
