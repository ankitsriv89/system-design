# Rate Limit Galaxy Frontend Plan

## Concept
Build an interactive space demo where each galaxy jump is protected by the real rate limiter. The user pilots a ship across a DESI-based cosmic web map. Allowed requests open a wormhole and move the ship; denied requests collapse the wormhole and show the limiter response.

## Scientific Map
- Use the DESI EDR Visualization and Outreach Catalog as the source universe map.
- Source file: `EDR-Viz-Outreach-VAC.csv.gz`
- Source URL: `https://data.desi.lbl.gov/public/edr/vac/edr/epoviz/v1.0/EDR-Viz-Outreach-VAC.csv.gz`
- Relevant fields: `TARGETID`, `RA`, `DEC`, `REDSHIFT`, `ROSETTE`, `TRACER`, `X`, `Y`, `Z`.
- Browser payload: `web/data/desi-sample.json`, generated by `scripts/sample_desi_epoviz.py`.

## Experience
- Full-screen animated cosmic web on Canvas.
- Ship starts near the center and travels to clicked DESI objects.
- Random jump button selects a catalog object and attempts a limiter check.
- Burst storm button fires many jumps quickly to demonstrate throttling.
- Token bucket and sliding window policies can be switched from the UI.
- HUD shows remaining capacity, retry-after cooldown, target metadata, and audit events.

## Backend Integration
- `POST /v1/limits/check` powers every jump.
- `PUT /v1/policies/{policy_id}` seeds demo policies from the UI or script.
- `GET /v1/usage/{subject}` returns recent audit decisions for the jump log.
- Static files are served by the Go server from `web/`.
- CORS is enabled so the UI can also run from a separate local dev server if needed.

## Visual Semantics
- Allowed: cyan wormhole opens, ship travels, fuel decreases, event log records success.
- Denied: red wormhole collapses, screen pulses, cooldown text shows `retry_after_ms`.
- Fuel bar visualizes the latest `remaining` value relative to demo policy capacity.
- DESI tracer colors:
  - QSO: gold
  - ELG: cyan
  - LRG: pink
  - BGS: green
