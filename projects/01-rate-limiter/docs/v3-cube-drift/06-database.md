# Database (`internal/cube/store.go`)

New tables only. **Never touch v1 tables** (`policies`, `audit_decisions`,
`odyssey_questions`, `odyssey_progress`). The existing `policies` table IS shared
(cube-server calls `policy.Store.Migrate` on startup, which is idempotent).

## New tables

```sql
-- Space object catalog: one row per curated object
CREATE TABLE IF NOT EXISTS cube_objects (
    object_id   TEXT        PRIMARY KEY,       -- "europa", "sgr-a", etc.
    name        TEXT        NOT NULL,
    kind        TEXT        NOT NULL,           -- planet|moon|asteroid|comet|dwarf|star|exoplanet|nebula|blackhole
    topic       TEXT        NOT NULL,           -- passed verbatim to Groq as the quiz topic
    zone        SMALLINT    NOT NULL            -- 0..3 difficulty zone
);

-- Quiz questions for cube objects (mirrors odyssey_questions, different key)
CREATE TABLE IF NOT EXISTS cube_questions (
    id          BIGSERIAL   PRIMARY KEY,
    object_id   TEXT        NOT NULL,
    question    TEXT        NOT NULL,
    choices     JSONB       NOT NULL,           -- ["A. ...", "B. ...", "C. ...", "D. ..."]
    answer      SMALLINT    NOT NULL CHECK (answer BETWEEN 0 AND 3),
    hint        TEXT        NOT NULL DEFAULT '',
    source      TEXT        NOT NULL DEFAULT 'seed',  -- "seed" | "groq"
    topic       TEXT        NOT NULL DEFAULT '',
    created_at  TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX IF NOT EXISTS cube_q_object_idx ON cube_questions(object_id);

-- Per-player game state (keyed by session id from HMAC cookie)
CREATE TABLE IF NOT EXISTS cube_games (
    session_id          TEXT        PRIMARY KEY,
    pos_x               SMALLINT    NOT NULL DEFAULT 0,
    pos_y               SMALLINT    NOT NULL DEFAULT 0,
    pos_z               SMALLINT    NOT NULL DEFAULT 0,
    score               INTEGER     NOT NULL DEFAULT 0,
    turn                INTEGER     NOT NULL DEFAULT 0,
    won                 BOOLEAN     NOT NULL DEFAULT false,
    seed                BIGINT      NOT NULL,
    pending_question_id BIGINT,                -- FK into cube_questions; NULL = no active question
    started_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at          TIMESTAMPTZ NOT NULL DEFAULT now()
);

-- Per-game board layout (warps + debris), stored as JSONB for fast reads
CREATE TABLE IF NOT EXISTS cube_boards (
    session_id  TEXT        PRIMARY KEY REFERENCES cube_games(session_id) ON DELETE CASCADE,
    seed        BIGINT      NOT NULL,
    layout      JSONB       NOT NULL    -- {"warps":[...],"debris":[...]}
);
```

## Key operations in CubeStore

```go
type CubeStore struct { db *sql.DB }

// Migrate runs the DDL above (idempotent CREATE TABLE IF NOT EXISTS).
func (s *CubeStore) Migrate(ctx context.Context) error

// SeedObjects inserts the curated catalog + seed questions (idempotent).
func (s *CubeStore) SeedObjects(ctx context.Context) error

// NewGame creates a cube_games row + cube_boards row in one transaction.
// seed is generated by the caller (crypto/rand).
func (s *CubeStore) NewGame(ctx context.Context, sessionID string, seed int64, layout []byte) (*GameState, error)

// GetGame loads GameState for the session; returns a zero-value (new player) if not found.
func (s *CubeStore) GetGame(ctx context.Context, sessionID string) (*GameState, error)

// GetBoard loads the Board JSON for the session's current game.
func (s *CubeStore) GetBoard(ctx context.Context, sessionID string) (*Board, error)

// SaveGame upserts the GameState.
func (s *CubeStore) SaveGame(ctx context.Context, st *GameState) error

// RandomQuestion returns a random cube_question for the given object_id.
// Returns sql.ErrNoRows if none exist (triggers Groq generation in the handler).
func (s *CubeStore) RandomQuestion(ctx context.Context, objectID string) (*Question, error)

// GetQuestionByID loads a single cube_question row by primary key.
func (s *CubeStore) GetQuestionByID(ctx context.Context, id int64) (*Question, error)

// SaveQuestion inserts a Groq-generated question and returns its id.
func (s *CubeStore) SaveQuestion(ctx context.Context, q *Question) (int64, error)
```

## Question type (mirrors odyssey.Question)

```go
type Question struct {
    ID       int64
    ObjectID string
    Question string
    Choices  json.RawMessage // JSON array of 4 strings
    Answer   int             // 0–3
    Hint     string
    Source   string          // "seed" | "groq"
    Topic    string
}
```
