Media Pipeline

Upload → store original in MinIO (PENDING) → emit media.uploaded → worker generates thumbnail/small/medium variants → mark PROCESSED → CDN serves variants by object key.

Feed Fanout

Hybrid model: push fanout into follower feeds (Redis ZSET) on post.created; pull-on-read for celebrity accounts above the follower threshold to avoid fanout storms.
