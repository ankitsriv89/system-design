Order Saga

A buyer adds products to a cart (stored in Redis), then checks out. Checkout atomically reserves inventory (PostgreSQL UPDATE with stock ≥ qty guard), creates an order in PENDING state, and publishes an order.created event to Kafka. The PaymentSagaConsumer picks it up and auto-approves payment (mock), transitioning the order to CONFIRMED. If inventory fails, the transaction rolls back with no partial state.
