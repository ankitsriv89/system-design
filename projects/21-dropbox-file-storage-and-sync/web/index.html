System Concepts

Metadata Tree vs Blob Storage

Files are stored as two separate concerns: metadata (name, path, owner, versions) in PostgreSQL, and blob data in object storage (MinIO/S3). This separation lets the database stay small and fast while blobs scale independently.

Sync Cursor Model

Each device maintains a sync_cursor — a pointer to the last change event it consumed. On GET /sync, the server returns all events since that cursor. Redis caches cursors to avoid hitting the DB on every poll.

Conflict Resolution Strategy

  • Last-write wins for simple edits (new version created)
  • Checksum dedup: identical content → no new version stored
  • Branched versions: concurrent writes from different devices create sibling versions; client UI resolves

Scale Levers

  • Partition Kafka topic by owner_id for parallelism
  • Redis caches hot folder listings (TTL: 30s)
  • S3 multipart API for files > 100 MB
  • Read replicas for listing-heavy workloads
